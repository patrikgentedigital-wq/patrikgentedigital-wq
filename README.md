## Sobre

Sou líder técnico na **Gente Digital**, um provedor de internet. Cuido de automações, integrações entre sistemas e das ferramentas que mantêm o atendimento e a operação funcionando. Nos repositórios abaixo, construo aplicações web em TypeScript com foco em autenticação, dados protegidos e deploy simples.

## No que trabalho

- **Aplicações web:** React + Vite, com interface responsiva e PWA instalável.
- **Backend gerenciado:** Firebase (Auth, Firestore, Cloud Functions) e Supabase (autenticação, persistência e regras de acesso).
- **Qualidade:** testes com Vitest, lint e build rodando antes de cada publicação.
- **IA aplicada:** geração de conteúdo e chat de estudo via OpenRouter e Gemini.

## Stack

`TypeScript` · `React` · `Vite` · `Tailwind CSS` · `Recharts` · `Vitest` · `Firebase` · `Supabase` · `Vercel`
